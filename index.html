当一个时代被彻底浪漫化，
是否意味着它真正的终局？有人怀念童年，有人怀念年少，有人怀念未曾经历的时代。

我们究竟在向往什么？

《故园旧梦》是一款以千禧年代中国旧居为场景的叙事探索游戏。玩家回到记忆中的房间，触摸旧物、打开电脑、倾听电视里的声音，并在三个夜晚进入不同的梦。

小时候，我们期待长大；长大后，我们开始怀念过去。梦中的人承载着不同年龄对未来的想象，而被怀念的年代，也渐渐混入了不属于它的事物。作品由此追问：我们向往的是某个时代，还是一个不必面对当下的自己？

探索旧物，与梦中人交谈，画下一条属于自己的鱼。随着三个夜晚展开，灯光、声音与熟悉的物件逐渐显露裂缝。最终，你沿楼梯离开旧居，再次望见曾经的梦境：鱼与记忆留在梦里，而人回到今时今日。

技术如何参与叙事

作品以同一间旧居为叙事空间，让灯光、声音、物件和电脑界面随三个夜晚发生变化。玩家亲手画下的鱼进入梦境，使记忆从被观看的图像变成可以参与的过程。技术在这里承担的是时间与记忆的组织：熟悉的空间逐渐变得陌生，玩家最终离开自己构筑的过去。

AI 辅助创作与人工贡献

我以对过去的怀念、对未来的想象，以及逃离当下的冲动为起点，构思了三个夜晚的叙事与交互，并在反复试玩中调整作品的视觉和体验。制作过程中，我使用 ChatGPT／Codex 与 Claude Code 辅助代码编写、调试和整合，也通过编写 Blender 脚本辅助三维建模、材质调整与场景搭建，并使用生成式图像工具制作部分视觉素材与候选方案。这些内容经过我的筛选与修改后融入作品。
